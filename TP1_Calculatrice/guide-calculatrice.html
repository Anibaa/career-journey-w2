Explication du projet fichier par fichier. Pour chaque formulaire : ce qu'on voit à l'écran, les propriétés imposées par l'énoncé, et le code ligne par ligne.

  • WinExeApplication avec fenêtres (pas de console noire au démarrage).
  • net8.0-windowsCible .NET 8, version Windows (obligatoire pour Windows Forms).
  • UseWindowsFormsAjoute les bibliothèques System.Windows.Forms et System.Drawing.
  • StartupObjectIndique que le programme démarre par Sub Main du module Program.
  • MyType« Windows Forms avec Sub Main personnalisé » : on écrit soi-même le démarrage au lieu de choisir un formulaire de démarrage dans les propriétés.

  • OptionExplicit OnToute variable doit être déclarée avec Dim.
  • EnableWindowsTargetingPermet de compiler aussi hors de Windows. Sans effet sur votre PC.

Le .sln regroupe un ou plusieurs projets. Il ne contient qu'une référence vers Calculatrice.vbproj et les configurations Debug / Release. Ouvrez toujours le .sln : avec « Ouvrir un dossier », F5 ne sait pas quel programme lancer (erreur « fichier introuvable »).

Module Program

    <STAThread>
    Sub Main()
        ' La virgule "," est utilisée comme séparateur décimal (culture française)
        Dim culture As New CultureInfo("fr-FR")
        CultureInfo.DefaultThreadCurrentCulture = culture
        CultureInfo.DefaultThreadCurrentUICulture = culture
        System.Threading.Thread.CurrentThread.CurrentCulture = culture
        System.Threading.Thread.CurrentThread.CurrentUICulture = culture

        Application.EnableVisualStyles()
        Application.SetCompatibleTextRenderingDefault(False)
        Application.Run(New frmMenu())

End Module
  • ModuleUn module contient des procédures partagées, sans objet à créer. C'est ici que vit Sub Main.
  • <STAThread>Attribut obligatoire pour une application Windows Forms (modèle de thread des fenêtres).
  • CultureInfo("fr-FR")Force le format français : Double.Parse("2,5") donne 2,5 et (0.5).ToString() affiche 0,5. L'énoncé demande la virgule, donc le programme fonctionne même sur un PC configuré en anglais.
  • EnableVisualStylesBoutons et zones de texte avec le style moderne de Windows.
  • Application.RunCrée le menu, l'affiche et fait tourner la boucle des événements. Le programme se termine quand ce formulaire se ferme.

Effectuer l'opération sélectionnée

Frmcalc1.vb
    Private Sub btncalculer_Click(sender As Object, e As EventArgs) Handles btncalculer.Click
        Dim a, b As Double

        If Not Double.TryParse(txtC1.Text, a) Then
            MessageBox.Show("Nombre 1 invalide.", "Erreur", MessageBoxButtons.OK, MessageBoxIcon.Warning)
            txtC1.Focus()
            Return
        End If
        If Not Double.TryParse(txtC2.Text, b) Then
            MessageBox.Show("Nombre 2 invalide.", "Erreur", MessageBoxButtons.OK, MessageBoxIcon.Warning)
            txtC2.Focus()
            Return
        End If

        If optPlus.Checked Then
            txtRes.Text = (a + b).ToString()
        ElseIf optMoins.Checked Then
            txtRes.Text = (a - b).ToString()
        ElseIf optMult.Checked Then
            txtRes.Text = (a * b).ToString()
        ElseIf optDiv.Checked Then
            If b = 0 Then
                MessageBox.Show("Division par zéro impossible.", "Erreur", MessageBoxButtons.OK, MessageBoxIcon.Error)
                txtRes.Text = "0"
            Else
                txtRes.Text = (a / b).ToString()
            End If
        Else
            MessageBox.Show("Veuillez choisir une opération.", "Erreur", MessageBoxButtons.OK, MessageBoxIcon.Information)
        End If
    End Sub
  • Double.TryParseEssaie de convertir le texte en nombre. Renvoie False au lieu de planter si le texte est vide ou incorrect (par ex. « , » seul). Si la conversion réussit, le nombre est rangé dans a ou b.
  • Focus() + ReturnPlace le curseur dans la zone fautive, puis quitte la procédure sans calculer.
  • .CheckedVaut True pour le bouton radio coché. La chaîne If … ElseIf choisit l'opération.
  • .ToString()Reconvertit le résultat en texte pour l'afficher (avec virgule, grâce à la culture fr-FR).
  • b = 0Avec des Double, diviser par zéro ne plante pas mais donne « +∞ ». On l'interdit donc nous-mêmes avec un message.

Filtrer la saisie avec KeyPress

Frmcalc1.vb
    ' Filtre la saisie : chiffres, une seule virgule et la touche Retour arrière (vbBack)
    Private Sub txtC_KeyPress(sender As Object, e As KeyPressEventArgs) Handles txtC1.KeyPress, txtC2.KeyPress
        Dim txt As TextBox = DirectCast(sender, TextBox)

        If Char.IsDigit(e.KeyChar) OrElse e.KeyChar = ControlChars.Back Then   ' ControlChars.Back = vbBack
            e.Handled = False
        ElseIf e.KeyChar = ","c AndAlso Not txt.Text.Contains(","c) Then
            e.Handled = False
        Else
            e.Handled = True   ' caractère refusé
        End If
    End Sub

    ' Sélectionne tout le contenu à l'entrée dans la zone de texte (pratique pour remplacer le "0")
    Private Sub txtC_Enter(sender As Object, e As EventArgs) Handles txtC1.Enter, txtC2.Enter
        DirectCast(sender, TextBox).SelectAll()
    End Sub
  • Handles A, BUne seule procédure gère les deux zones de texte. sender indique laquelle a déclenché l'événement.
  • DirectCastsender est de type Object. On le convertit en TextBox pour pouvoir lire sa propriété .Text.
  • e.KeyCharLe caractère de la touche pressée.
  • e.HandledTrue signifie « je m'en occupe » : le caractère n'est pas écrit dans la zone de texte. C'est ainsi qu'on refuse une lettre.
  • ControlChars.BackLe caractère Retour arrière, identique à vbBack. On utilise la version Char car vbBack est une String, et Option Strict refuse de comparer un Char à une String.
  • ","cLe suffixe c crée un Char au lieu d'une String. Le test Not txt.Text.Contains(","c) n'autorise qu'une seule virgule.
  • SelectAllBonus : en entrant dans la zone, le « 0 » est sélectionné et il est remplacé dès qu'on tape.

Ces variables sont déclarées au niveau de la classe (hors de toute procédure) : elles gardent leur valeur entre deux clics. Une calculatrice doit se souvenir du premier nombre et de l'opération pendant que vous tapez le second.

Frmcalc2.vb
    Private Sub Chiffre_Click(sender As Object, e As EventArgs) Handles _
            btn0.Click, btn1.Click, btn2.Click, btn3.Click, btn4.Click,

    Private Sub SaisirChiffre(chiffre As String)
        ReinitialiserSiErreur()
        If nouvelleSaisie OrElse txtAffichage.Text = "0" Then
            txtAffichage.Text = chiffre
        ElseIf txtAffichage.Text = "-0" Then
            txtAffichage.Text = "-" & chiffre
        Else

        End If
        nouvelleSaisie = False
    End Sub

BoutonEffet
,Ajoute une virgule, une seule fois. Au début d'un nombre, écrit « 0, ».
+/-Ajoute ou enlève le « - » devant le nombre. Substring(1) = le texte sans son 1er caractère.
Retour arrièreSupprime le dernier caractère avec Substring(0, Length - 1). S'il ne reste rien, affiche 0. N'efface pas un résultat déjà calculé.
CEClear Entry : efface le nombre en cours mais garde le calcul (ex. 12 + 5 → CE → 3 = donne 15).
CClear : remet tout à zéro, y compris l'opération en attente.

Les opérations binaires : + − × ÷ ^

Frmcalc2.vb
    Private Function Calculer(a As Double, b As Double, op As String) As Double
        Select Case op
            Case "+" : Return a + b
            Case "-" : Return a - b
            Case "*" : Return a * b
            Case "/"
                If b = 0 Then Throw New DivideByZeroException()
                Return a / b
            Case "^" : Return Math.Pow(a, b)
            Case Else : Return b
        End Select
    End Function

    Private Sub Operateur_Click(sender As Object, e As EventArgs) Handles _
            btnPlus.Click, btnMoins.Click, btnMult.Click, btnDiv.Click, btnPuissance.Click
        AppliquerOperateur(DirectCast(sender, Button).Text)
    End Sub

    Private Sub AppliquerOperateur(op As String)
        If enErreur Then Return
        Try
            ' Enchaînement (ex : 2 + 3 * ...) : on calcule d'abord l'opération en attente
            If Not nouvelleSaisie AndAlso operateurEnAttente <> "" Then
                accumulateur = Calculer(accumulateur, ValeurAffichee, operateurEnAttente)
                Afficher(accumulateur)
                If enErreur Then Return
            ElseIf operateurEnAttente = "" Then
                accumulateur = ValeurAffichee
            End If
            operateurEnAttente = op
            nouvelleSaisie = True
        Catch ex As DivideByZeroException
            AfficherErreur("Division par zéro impossible")
        End Try
    End Sub
  • Function CalculerUne Function renvoie une valeur, contrairement à une Sub. Select Case choisit le calcul selon le texte de l'opérateur. Math.Pow(a, b) calcule ab (bouton ^).
  • ThrowEn cas de division par zéro, la fonction lève une exception au lieu de renvoyer un résultat faux.
  • Try … CatchIntercepte cette exception et affiche un message d'erreur au lieu de planter le programme.
  • Les 3 cas1) Un nombre a été tapé et une opération attend → on la calcule d'abord (enchaînement). 2) Aucune opération en attente → le nombre affiché devient l'accumulateur. 3) On appuie sur deux opérateurs de suite → seul l'opérateur change.

Le bouton =

Frmcalc2.vb
    Private Sub Egal()
        If enErreur OrElse operateurEnAttente = "" Then Return
        Try
            Dim resultat As Double = Calculer(accumulateur, ValeurAffichee, operateurEnAttente)
            operateurEnAttente = ""
            accumulateur = 0
            Afficher(resultat)
            nouvelleSaisie = True
        Catch ex As DivideByZeroException
            AfficherErreur("Division par zéro impossible")
        End Try
    End Sub

Calcule accumulateur (opérateur) valeur affichée, affiche le résultat et vide l'opération en attente. Le chiffre tapé ensuite commencera un nouveau nombre.

Elles agissent tout de suite sur le nombre affiché, sans attendre =. La racine d'un nombre négatif et l'inverse de 0 sont interdits. Une opération en attente est conservée : 9 + 16 Rac = donne 9 + 4 = 13.

Affichage et gestion des erreurs

Frmcalc2.vb
    Private Sub Afficher(valeur As Double)
        If Double.IsNaN(valeur) OrElse Double.IsInfinity(valeur) Then
            AfficherErreur("Résultat non défini")
        Else
            txtAffichage.Text = valeur.ToString()
        End If
    End Sub

    Private Sub AfficherErreur(message As String)
        txtAffichage.Text = message
        accumulateur = 0
        operateurEnAttente = ""
        nouvelleSaisie = True
        enErreur = True
    End Sub

    Private Sub ReinitialiserSiErreur()
        If enErreur Then
            enErreur = False
            txtAffichage.Text = "0"
            nouvelleSaisie = True
        End If
    End Sub
  • NaN / InfinityCertains calculs donnent « pas un nombre » (ex. (−8)^0,5) ou l'infini (ex. 10^400). On affiche alors un message au lieu de « NaN » ou « ∞ ».
  • enErreurPendant qu'un message est affiché, les opérations sont ignorées. Taper un chiffre, la virgule, Retour arrière, CE ou C fait repartir de 0.

Bonus : le clavier

    Private Sub Frmcalc2_KeyPress(sender As Object, e As KeyPressEventArgs) Handles Me.KeyPress

Grâce à KeyPreview = True, le formulaire voit chaque touche. PerformClick() simule un clic sur un bouton. Échap fait C, . et , donnent la virgule.
