Traitement de texte en C# Windows Forms

Une fenêtre de connexion, puis un éditeur qui compte les mots et construit un dictionnaire. Chaque fichier est expliqué ici, avec le code et une maquette de l'éditeur que vous pouvez essayer.

Vue d'ensemble

Le programme s'ouvre sur frmAuth. Si le login et le mot de passe sont bons (admin / 1234), la fenêtre de connexion se cache et l'éditeur s'ouvre. Quand l'éditeur se ferme, le programme se termine.

Ce TP est écrit en C# car l'énoncé donne ses exemples en C# (private void, using System.IO;, Clipboard.cs). Le TP1 était en VB.NET.

Program.cs
using System;
using System.Globalization;
using System.Threading;
using System.Windows.Forms;

namespace TraitementDeTexte
{
    internal static class Program
    {
        [STAThread]
        static void Main()
        {
            // Culture française : tri alphabétique correct des mots accentués (é, è, à...)
            CultureInfo culture = new CultureInfo("fr-FR");
            CultureInfo.DefaultThreadCurrentCulture = culture;
            CultureInfo.DefaultThreadCurrentUICulture = culture;
            Thread.CurrentThread.CurrentCulture = culture;
            Thread.CurrentThread.CurrentUICulture = culture;

            Application.EnableVisualStyles();
            Application.SetCompatibleTextRenderingDefault(false);
            Application.Run(new frmAuth());
        }
    }
}
  • static void MainLa première méthode exécutée. [STAThread] est obligatoire pour Windows Forms.
  • fr-FRLe dictionnaire est trié selon la culture courante. En français, « séparateurs » vient avant « servira » (le é est rangé avec le e). Sans ça, l'ordre dépendrait de la langue du PC.
  • Application.RunAffiche frmAuth et fait tourner le programme jusqu'à sa fermeture.

Designer et événements en C#

Comme au TP1, chaque formulaire est une classe en deux morceaux (partial class) : le fichier .Designer.cs crée l'interface, le fichier .cs contient votre code.

Différence avec VB.NET : C# n'a pas de Handles. Un bouton est relié à sa méthode par += dans le Designer :

frmAuth.Designer.cs (extrait)
this.btnOk.Text = "&Ok";
this.btnOk.Click += new System.EventHandler(this.btnOk_Click);

Dans Visual Studio, ce lien est créé automatiquement quand vous double-cliquez sur un bouton dans le Concepteur. Si vous renommez ou supprimez une méthode à la main, supprimez aussi la ligne += correspondante, sinon le projet ne compile plus.

frmAuth.cs
public partial class frmAuth : Form
{
    // Login et mot de passe attendus
    private const string LOGIN = "admin";
    private const string MOT_DE_PASSE = "1234";

    public frmAuth()
    {
        InitializeComponent();
    }

    // Ok : vérifie le login et le mot de passe avant de charger Frmedit
    private void btnOk_Click(object sender, EventArgs e)
    {
        if (txtLogin.Text == LOGIN && Txtpass.Text == MOT_DE_PASSE)
        {
            this.Hide();
            using (Frmedit f = new Frmedit())
            {
                f.ShowDialog();
            }
            this.Close();   // quand l'éditeur se ferme, l'application se termine
        }
        else
        {
            MessageBox.Show("Login ou mot de passe incorrect.", "Erreur",
                MessageBoxButtons.OK, MessageBoxIcon.Error);
            Txtpass.Clear();
            Txtpass.Focus();
        }
    }

    // Annuler : quitte l'application
    private void btnAnnuler_Click(object sender, EventArgs e)
    {
        Application.Exit();
    }
}
  • const stringConstantes : les identifiants attendus, écrits une seule fois en haut de la classe. Changez-les ici pour choisir votre propre login.
  • public frmAuth()Le constructeur, appelé par new frmAuth(). InitializeComponent() crée les contrôles du Designer.
  • &&« ET » logique : les deux conditions doivent être vraies.
  • this.Hide()Cache la fenêtre de connexion sans la détruire. Si on la fermait, Application.Run se terminerait et le programme s'arrêterait.
  • ShowDialog()Ouvre l'éditeur et attend sa fermeture. Ensuite this.Close() ferme la connexion, ce qui termine le programme.
  • using (…)Libère les ressources de l'éditeur (Dispose) une fois fermé.
  • elseMauvais identifiants : message d'erreur, mot de passe effacé, curseur replacé dans Txtpass.

Qu'est-ce qu'un mot ? L'expression régulière

Frmedit.cs
// Un mot = une suite de lettres (accents compris) ou de chiffres.
// Tout le reste (espaces, ponctuation, retours à la ligne...) est un séparateur.
private static readonly Regex regexMot = new Regex(@"[\p{L}\p{M}\p{N}]+");
  • RegexUne expression régulière décrit un motif de texte. Elle vient de using System.Text.RegularExpressions;.
  • [ … ]+« un ou plusieurs caractères parmi… ». Chaque bloc trouvé est un mot.
  • \p{L} \p{M} \p{N}Toute lettre (y compris é, è, ç), les accents combinés, et tout chiffre. Les espaces, points, virgules, apostrophes ne correspondent pas : ce sont les séparateurs.
  • @"…"Chaîne « verbatim » : le \ est pris tel quel, pas besoin d'écrire \\p.
  • static readonlyCréée une seule fois pour toute la classe, et non modifiable ensuite.

Compter les mots au fur et à mesure (TextChanged)

Frmedit.cs
private void Frmedit_Load(object sender, EventArgs e)
{
    AfficherNombreDeMots();
    MettreAJourDictionnaire();
}

// ---------- Nombre de mots (mis à jour au fur et à mesure de la saisie) ----------
private void Txt_saisir_TextChanged(object sender, EventArgs e)
{
    AfficherNombreDeMots();
}

private void AfficherNombreDeMots()
{
    int nb = regexMot.Matches(Txt_saisir.Text).Count;
    lblNbMots.Text = "Nombre de mots : " + nb;
}

L'énoncé propose deux événements. TextChanged se déclenche à chaque modification du texte : le compteur est toujours à jour. Validated ne se déclencherait qu'en quittant la zone de texte. On a choisi TextChanged.

regexMot.Matches(…) renvoie tous les mots trouvés ; .Count donne leur nombre. Au chargement (Load), le compteur et le dictionnaire sont calculés une première fois pour le texte d'exemple.

Le dictionnaire

Frmedit.cs
private void btn_maj_Click(object sender, EventArgs e)
{
    MettreAJourDictionnaire();
}

private void MettreAJourDictionnaire()
{
    // Compte les répétitions de chaque mot (en minuscules : "Le" et "le" = même mot).
    // SortedDictionary garde les mots triés dans l'ordre alphabétique français.
    SortedDictionary<string, int> dico = new SortedDictionary<string, int>(StringComparer.CurrentCulture);

    foreach (Match m in regexMot.Matches(Txt_saisir.Text))
    {
        string mot = m.Value.ToLower();
        if (dico.ContainsKey(mot))
            dico[mot]++;
        else
            dico[mot] = 1;
    }

    lstDictionnaire.BeginUpdate();
    lstDictionnaire.Items.Clear();
    foreach (KeyValuePair<string, int> entree in dico)
    {
        lstDictionnaire.Items.Add(entree.Key + "  " + entree.Value);
    }
    lstDictionnaire.EndUpdate();
}
  • SortedDictionary<string, int>Une table clé → valeur : le mot → son nombre de répétitions. « Sorted » : les clés restent toujours triées.
  • StringComparer.CurrentCultureTrie selon la langue (fr-FR, réglée dans Program.cs), donc les mots accentués sont à la bonne place.
  • ToLower()Met le mot en minuscules : « Le » et « le » comptent comme le même mot. Résultat attendu dans l'énoncé : le 2.
  • ContainsKeySi le mot est déjà dans la table, on augmente son compteur (++). Sinon on l'ajoute avec 1.
  • foreachParcourt les mots dans l'ordre alphabétique et ajoute une ligne « mot n » dans la ListBox.
  • BeginUpdate / EndUpdateLa ListBox ne se redessine qu'une fois à la fin, au lieu d'une fois par mot.

3) Optionnel : Enregistrer dans un fichier

Frmedit.cs
private void btn_enregistrer_Click(object sender, EventArgs e)
{
    saveFileDialog1.Filter = "txt files (*.txt)|*.txt";

    if (saveFileDialog1.ShowDialog() == System.Windows.Forms.DialogResult.OK
        && saveFileDialog1.FileName.Length > 0)
    {
        StreamWriter sr = File.CreateText(saveFileDialog1.FileName);
        sr.Write(Txt_saisir.Text);
        sr.Close();
        MessageBox.Show("Texte enregistré dans :\n" + saveFileDialog1.FileName, "Enregistrer",
            MessageBoxButtons.OK, MessageBoxIcon.Information);
    }
}
  • SaveFileDialogLa boîte Windows « Enregistrer sous ». On l'ajoute depuis la Boîte à outils ; elle apparaît sous le formulaire dans le Concepteur.
  • FilterFormat "description|motif" : seuls les fichiers .txt sont proposés.
  • DialogResult.OKL'utilisateur a cliqué sur « Enregistrer » et non « Annuler ». On écrit le nom complet System.Windows.Forms.DialogResult car DialogResult est aussi une propriété du formulaire.
  • File.CreateTextCrée (ou remplace) le fichier et renvoie un StreamWriter pour écrire dedans. Vient de using System.IO;.
  • Write / CloseÉcrit tout le texte, puis ferme le fichier. Sans Close(), le fichier pourrait rester vide ou verrouillé.

3) Optionnel : le menu contextuel et la classe Clipboard Clipboard.cs · Frmedit.cs

Clipboard.cs
namespace TraitementDeTexte
{
    // Presse-papiers interne de l'application (menu contextuel copier / couper / coller)
    class Clipboard
    {
        public static string copier;
    }
}
  • staticLa variable appartient à la classe et non à un objet : on écrit Clipboard.copier sans faire de new. Il n'en existe qu'une seule dans tout le programme, donc le texte copié est conservé entre deux clics.
  • publicAccessible depuis Frmedit (et tout autre formulaire).
  • Nom Clipboard.NET a déjà une classe System.Windows.Forms.Clipboard. Comme la nôtre est dans le même espace de noms que Frmedit (TraitementDeTexte), c'est la nôtre qui est utilisée.
Frmedit.cs
// ---------- Menu contextuel "Mnu" : copier / couper / coller ----------
private void Mnu_Opening(object sender, CancelEventArgs e)
{
    bool selection = Txt_saisir.SelectionLength > 0;
    mnuCopier.Enabled = selection;
    mnuCouper.Enabled = selection;
    mnuColler.Enabled = !string.IsNullOrEmpty(Clipboard.copier);
}

private void mnuCopier_Click(object sender, EventArgs e)
{
    Clipboard.copier = Txt_saisir.SelectedText;
}

private void mnuCouper_Click(object sender, EventArgs e)
{
    Clipboard.copier = Txt_saisir.SelectedText;
    Txt_saisir.SelectedText = "";
}

private void mnuColler_Click(object sender, EventArgs e)
{
    // Remplace la sélection (ou insère à la position du curseur)
    Txt_saisir.SelectedText = Clipboard.copier;
}
ÉlémentRôle
Mnu (ContextMenuStrip)Le menu du clic droit, avec 3 éléments : mnuCopier, mnuCouper, mnuColler. Il est lié à la zone par Txt_saisir.ContextMenuStrip = Mnu.
Mnu_OpeningJuste avant l'ouverture du menu : grise Copier/Couper s'il n'y a pas de sélection, grise Coller si rien n'a encore été copié.
SelectedTextLire = le texte sélectionné. Écrire = remplacer la sélection (ou insérer au curseur s'il n'y a pas de sélection).
CopierMémorise la sélection dans Clipboard.copier.
CouperMémorise la sélection, puis la remplace par "" (elle disparaît).
CollerÉcrit Clipboard.copier à la place de la sélection.

Ce presse-papiers est interne au programme : un texte copié ici ne peut pas être collé dans Word, et inversement. Ctrl+C / Ctrl+V continuent d'utiliser le presse-papiers de Windows.
